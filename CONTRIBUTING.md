# Contributing to Zethora

Zethora is built in the open. Thank you for helping.

## Where things stand
- Specs: Draft v0.1, open for comment ([specs/](./specs/))
- Code: first reference tool ([tools/emission](./tools/emission/)); node not started
- Planned stack: Rust, starting from Kaspa's open-source BlockDAG code

## How to help
1. **Review a spec.** Find a mistake, risk, or better idea? Open an Issue that names the spec and section (e.g. "SPEC-005 §3").
2. **Discuss.** Questions and ideas go in Discussions.
3. **Propose a change.** Larger changes become a Zethora Improvement Proposal (ZIP). Open a Discussion first.
4. **Write code.** Pick an Issue labeled `good first issue` or `help wanted`, comment that you're on it, then open a pull request.

## Most needed
Rust · consensus (GHOSTDAG/Kaspa) · RandomX · zero-knowledge proofs (Halo2) · Monero-style privacy · wallets · security review

## Rules that never change
- No premine, no presale, no founder coins. Contributors get credit, never coins.
- No admin keys, pause buttons, or freeze powers in the protocol.
- The money rules in SPEC-001 §4–7 are frozen.

## Security
Found a vulnerability? Do **not** open a public Issue. Use **Security → Report a vulnerability** on this repo.

## Conduct
Be respectful. Critique ideas, not people.
